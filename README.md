# Smart Support Hub

Учебная веб-платформа внедрения, эксплуатации и сопровождения программного продукта.

## Запуск

Откройте папку в VS Code и запустите Live Server либо выполните:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Нужен современный браузер. Сборка и npm не требуются.

## Состав

- `index.html` — четыре показателя и графики Chart.js.
- `deployments.html` — внедрения, этапы, прогресс и добавление.
- `incidents.html` — регистрация, фильтр, решение и SLA.
- `maintenance.html` — четыре вида заявок, статусы и целевая версия.
- `releases.html` — выпуски и расчёт SemVer.
- `assets/css/` и `assets/js/` — отдельные стили и логика.
- `assets/vendor/chart.umd.js` — Chart.js 4.4.8, лицензия MIT в заголовке файла.
- `docs/USER_GUIDE.md` — руководство пользователя.

## Хранение и границы прототипа

Данные и тема сохраняются в localStorage с префиксом `ssh.`. Это локальный учебный прототип: нет сервера, авторизации и общего хранилища команды. Разные браузеры имеют независимые данные. При первом запуске даты учебных инцидентов задаются относительно текущего времени, затем сохраняются. Названия и ответственные вымышлены.

SLA: critical 4 ч, high 8 ч, medium 24 ч, low 72 ч. Процент SLA считается только по решённым инцидентам; если их нет, выводится 100%. Активным считается внедрение, ещё не перешедшее в production. История продукта содержит учебную запись v0.9.0; реальные версии исходного кода отмечены Git-тегами v1.0.0 и v1.1.0.

## Публикация в GitHub Pages

Создайте публичный репозиторий `smart-support-hub`, отправьте ветку `main` и теги. В Settings → Pages выберите Deploy from a branch → main → /(root). Исходные HTML должны находиться в корне репозитория. Файл .nojekyll уже включён.

```sh
git remote add origin https://github.com/YOUR_LOGIN/smart-support-hub.git
git push -u origin main
git push origin --tags
```

## Проверка

Обязательные сценарии и результаты проверки помещены в отчёт. Логику SLA и SemVer можно проверить без браузера командой `node tests/logic.test.cjs`.
